# Number Guessing Game 🎯

A simple terminal-based Number Guessing Game built using Python.

## Features
- Random number generation
- Easy & Hard difficulty levels
- Attempt tracking system
- Interactive command-line gameplay
- User guess validation

## Concepts Used
- Functions
- Loops
- Conditional Statements
- Random Module
- Game Logic

## Technologies Used
- Python
